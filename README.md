# Capstone Regulatory Document Assistant

A 30-week build of a Q&A assistant  over FDA clinical-trial documents completed as a part of the Agentic AI & RAG Engineering programme.

## Corpus

My capstone corpus: FDA guidance documents on clinical trial studies (e.g., ICH E6(R2) Good Clinical Practice, adaptive trial design guidance, 21 CFR Part 312). Source: fda.gov guidance documents database.

## Structure

- `src/` - application code
- `docs/adr/` - Architecture Decision Records (one per major decision choice)
- `docs/runs/` - saved LLM outputs for evidence and reference
